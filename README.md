# GREEN-API Chat

Веб-чат на React и TypeScript для отправки и получения текстовых сообщений через [GREEN-API](https://green-api.com).

## Возможности

Основное:
- Вход по `idInstance` и `apiTokenInstance`; перед входом проверяется, что инстанс авторизован (`getStateInstance`).
- Новый чат по номеру телефона получателя (кнопка ✏️ внизу списка чатов): `chatId` находится через `checkAccount`. Сразу можно написать первое сообщение.
- Отправка текстовых сообщений методом `sendMessage`.
- Получение входящих через HTTP API: `receiveNotification` в цикле и `deleteNotification` после обработки каждого уведомления. Показываются только текстовые сообщения (включая ответы — `quotedMessage`).

Небольшие дополнения для удобства:
- Список существующих чатов (`getChats`) с последним сообщением и отправителем; при открытии чата — последние 50 текстовых сообщений (`getChatHistory`).
- Статусы отправленных: отправлено ✓, доставлено ✓✓, прочитано (цветные ✓✓) — из уведомлений `outgoingMessageStatus`.
- Фото профиля собеседника (`getAvatar`); если фото нет — первая буква имени.
- Поиск по списку чатов, счётчик непрочитанных, выход из аккаунта в меню ☰.
- Адаптивная вёрстка: на телефоне список чатов и окно чата открываются по очереди.

## Запуск локально
Нужен Node.js 20 или новее.

```bash
git clone <ссылка на репозиторий>
cd greenapi-chat
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Как пользоваться
1. В [личном кабинете GREEN-API](https://console.green-api.com) создайте и авторизуйте инстанс.
2. Введите `idInstance` и `apiTokenInstance`. Поле `apiUrl` заполняется само по первым четырём цифрам `idInstance`; если в кабинете указан другой адрес, вставьте его.
3. Введите номер получателя (например, `79991234567`) или его `@username` и нажмите «Создать».
4. Напишите сообщение и отправьте его кнопкой или клавишей Enter (Shift+Enter переносит строку).
5. Ответ собеседника появится в чате через несколько секунд.

> У инстанса не должен быть задан `webhookUrl`: пока он указан, получение через HTTP API не работает.
>
> В настройках инстанса должны быть включены «Получать уведомления о входящих сообщениях» (`incomingWebhook`) и, для галочек доставки и прочтения, «Получать уведомления о статусах исходящих сообщений» (`outgoingWebhook`).

## Структура
```
src/
  api/greenApi.ts            запросы к GREEN-API
  hooks/useNotifications.ts  цикл получения входящих уведомлений
  components/                LoginForm, Sidebar, ChatWindow
  App.tsx                    состояние чатов (useReducer)
  types.ts                   типы
```

Данные для входа хранятся в `sessionStorage` и удаляются после закрытия вкладки или выхода. История сообщений хранится только в памяти.

## Сборка
```bash
npm run build     # проверка типов и сборка в dist/
npm run preview   # локальный просмотр собранной версии
```
